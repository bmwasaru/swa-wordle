# Maneno

This is a clone of a clone project of the popular word guessing game we all know and love. Made using React, Typescript, and Tailwind. The clone of the clone is here [wordle](https://github.com/thesam73/wordle). Changes were made for the Kiswahili langauge.

## Live Site
You can find the live web app for this here [maneno.kamusi.io](https://maneno.kamusi.io/)
